# Flashlight App

A simple Flashlight app built using Kotlin and Jetpack Compose.

## Features
- Toggle flashlight ON/OFF
- Simple and minimal UI
- Uses Camera permission to control the flashlight

## Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **Camera2 API**

## Requirements
- Android 6.0 (API Level 23) and above
- Camera Permission
